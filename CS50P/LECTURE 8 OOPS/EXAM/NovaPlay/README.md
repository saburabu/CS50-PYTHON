# NovaPlay — OOP Codebase Rescue

Welcome to NovaPlay, a small command-line gaming library application.

You have inherited this project from another developer. The application is partly functional, but it needs investigation, debugging, and improvements before it can be extended.

## Requirements

- Python 3.10+
- No third-party packages required

## Run the application

From this folder, run:

```bash
python main.py
```

## Current functionality

- View the game catalogue
- Register and list users
- Add funds to a wallet
- Purchase games
- View a user's game library
- View purchase history

## Your assignment

1. Explore the codebase and understand how its parts interact.
2. Investigate incorrect behaviour and repair it.
3. Improve the object-oriented design where appropriate.
4. Keep existing working behaviour intact.
5. After the rescue work, add:
   - Game reviews
   - Wishlists
   - Refund requests for eligible purchases
   - Game categories
   - Library statistics

## Working agreement

- Do not rewrite the entire project just to make it look different.
- Make small, reasoned changes.
- Test the behaviour after each meaningful change.
- Keep a short engineering log explaining what you changed and why.

The project intentionally contains defects and design weaknesses. Discover them through code reading and testing; this README does not identify them.
